# Cub3D

## Description

The objective is to create a dynamic view iniside a 3D map. Using the Minilbx library, we must implement raycasting in the style of Wolfstein 3D.

## Instructions

This projects includes a Makefile, making it more easy to complie with the use of the _make_ command from the root of of the project.

Once compiled, to execute it, write _./cub3D <path to map.cub>_.

The program takes a map file as an argument. Maps are available in the assets/maps directory

## Controls

- `W`: move forward
- `S`: move backward
- `A`: strafe left
- `D`: strafe right
- `left arrow`: rotate left
- `right arrow`: rotate right
